# Matriz de garantias do harness

O que cada mecanismo do plugin garante, o que não garante e o que prova isso. Estado: **VERIFICADO** (um teste do
wstack mostra o caso positivo e o negativo), **IMPLEMENTADO** (existe e roda, sem teste que mostre os dois lados),
**NÃO VERIFICADO** (depende do Claude Code real e não foi medido nesta versão). Os testes estão em `plugin/tests/` e
rodam no CI (`.github/workflows/ci.yml`); as provas `prove-*.sh` usam o Claude Code real e rodam à mão; as medições
`measure-*.sh` rodam à mão na máquina do projeto (custo dos hooks por comando, pedidos de aprovação de uma sessão, hook
de fim com a saída do build travada) e não decidem estado nesta tabela.

Versão 0.0.51: hooks, scripts, skills, agentes e o `/wstack:bootstrap` com os modelos do projeto (`plugin/templates`).

## Riscos aceitos

- **Caminho montado para esconder.** Os guardas de Bash leem o texto do comando: um caminho montado em variável,
  quebrado por aspas no meio do nome ou gerado por outro programa não aparece como trava. O hook é cinto de
  segurança, não fronteira (`docs/decisions.md`, trava mínima nos comandos); a fronteira é o PR, o isolamento e o
  `deny`.
- **Comando que troca a árvore inteira sem citar a trava** (`git checkout <ref> -- .`, extração de arquivo
  compactado na raiz): muda arquivos protegidos sem citá-los. O push-guard e o `checkpoint.sh` conferem o que sai da
  máquina.
- **Repositório sem bootstrap.** O plugin instalado no escopo do usuário roda em todo repositório; ali os hooks de
  workflow ficam inertes e as travas seguem só com o núcleo (`docs/decisions.md`, plugin inerte sem risk.conf). Apagar
  o `risk.conf` da árvore, pôr o HEAD num commit anterior ao bootstrap, trocar commits com `git replace` ou apagar as
  branches e refs de rastreio não deixa o projeto inerte enquanto o arquivo estiver num commit apontado (os reflogs
  incluídos). Sobra limpar também os reflogs, uma sequência de comandos que um a um não citam a trava; um commit que apaga
  o arquivo é mudança em caminho protegido, que o push-guard pede para publicar.
